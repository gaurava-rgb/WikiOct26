# Why AI-Written Software Needs a Flight Simulator

Laura Bratton, The Information, published 2026-10-15.

## Summary

Surging enterprise adoption of AI-generated code has driven demand for deterministic testing software that repeatedly simulates network disasters and rogue AI attacks. Replit uses deterministic simulators from Virginia startup Antithesis, which counts Palantir and Datadog among its customers. Antithesis booked more new revenue in the August 2026 quarter than in the preceding five quarters combined after raising $105 million from Jane Street, while competitors Microsoft and Amazon sell live server fault-injection tools.

## Key claims

- Replit uses deterministic simulation software as a flight simulator to repeatedly test AI-written applications against network disasters and cyberattacks. (§ Need for deterministic simulation in AI code generation: “Replit chief technology officer Luis Chávez stated his team relies on deterministic simulation software that functions as a flight simulator for code”) ^clm-fcd47102d2f46d5b1635
- Using generative AI models to evaluate code generates false alarms because probabilistic models behave inconsistently across repeated runs. (§ Need for deterministic simulation in AI code generation: “using generative AI to evaluate code frequently generates false alarms and hallucinatory warnings”) ^clm-0e340c1a7ba8872cc7a7
- Antithesis CEO Will Wilson argues that while AI made code generation simpler, verifying that software works correctly did not get easier. - Antithesis generated more incremental revenue in the August 2026 quarter than across all five preceding quarters combined.
