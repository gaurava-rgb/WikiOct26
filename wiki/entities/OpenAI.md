- On 2026-04-27 Microsoft and OpenAI amended their deal so OpenAI can serve all its products on any cloud provider, including AWS; Microsoft stays the primary cloud partner and products ship first on Azure. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-3912d088973d129a218b|cite]])
- Under the new deal Microsoft keeps a license to OpenAI models and products through 2032, but the license is now non-exclusive. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-bf11d810f08b2490979b|cite]])
- Microsoft no longer pays a revenue share to OpenAI; OpenAI's revenue share payments to Microsoft continue through 2030 at the same percentage but with a total cap. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-cc8e40aad2f8d330b062|cite]])
- OpenAI released Microsoft from the AGI clause (a term that could end the deal once OpenAI reached human-level AI), so the agreement runs through 2032 no matter what. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-216dedabf6ebb743cc36|cite]])
- Thompson argues Azure's exclusive hold on OpenAI models was hurting Microsoft's investment in OpenAI, because enterprises want models on the cloud they already use, which helped Anthropic grow. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-668b4b337ea46e815a22|cite]])
- Thompson argues OpenAI sees AWS as so big an opportunity that it gave up Azure-related revenue for the next few years to get there. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-2ba4e3f00655a4d28e89|cite]])
- Thompson describes Bedrock Managed Agents, powered by OpenAI, as Codex in AWS: OpenAI frontier models packaged inside an AWS-native agent runtime with identity, permissions, logging, governance, and deployment. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-6f9f326aee5a1266959b|cite]])
- Garman agrees that a common startup pattern is AWS for regular computing plus the OpenAI API directly for AI. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-1cb112ea83e55e1bd4db|cite]])
- Altman says the harness (the software around the model: tools, memory, permissions) and the model are no longer separable, and he expects them to merge further over time, as tool-calling did. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-d77c3cd156dba0207161|cite]])
- Thompson argues the harness-model integration is the key integration point in the AI value chain, where value will collect; Altman agrees. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-31db6aae9a5b31c75620|cite]])
- Garman says that before this product, customers had to wire agents into their own data, tools, and systems on their own; the joint product builds in identity and keeps database access inside the customer's AWS VPC (a private network in AWS). ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-54497147a8dd6eddd6d3|cite]])
- Altman says Codex first ran in the cloud but moved to the user's local computer because it was easier to get working, though he expects agents to end up running in the cloud. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-ce841691b528a47a63d9|cite]])
- Garman says Bedrock Managed Agents was co-built by AWS and OpenAI teams from AgentCore components, AWS's existing set of agent building blocks (memory, safe execution, permissions). ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-28ac6921267337c607e9|cite]])
- Altman says the managed agent offering is exclusive to Amazon, and says it is distinct from the plain API access OpenAI offers on Azure. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-bd90d55e7500825f258f|cite]])
- Prediction: Garman says the OpenAI models in Bedrock will run partly on Trainium (Amazon's own AI chip) and partly on GPUs, with more moving to Trainium over time. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-5743bddeb6ddab3e1294|cite]])
- Altman says OpenAI's GPT-5.5 costs much more per token than 5.4 but needs far fewer tokens for the same answer, mostly due to the model, so per-token pricing may not last. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-0a16efd8f804cddec404|cite]])
- Altman says OpenAI must be an intelligence factory, delivering the most units of intelligence at the lowest price, and customers do not care about the chip or model size underneath. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-3769e62921b2f6f23f4d|cite]])
- Garman says AWS will be frontline support for Bedrock Managed Agents and will escalate bugs to OpenAI when needed. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-fe9693c18c4047f76271|cite]])
- Altman says OpenAI is committing to buy a lot of compute for this business and believes that at a low enough price, demand for intelligence is essentially uncapped. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-fd597abce89e68273b1a|cite]])
- Altman says far more customers ask OpenAI for more capacity at any price than argue about price, and that so far most demand is for the absolute frontier (newest, best) models. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-bdf289252b65063467d8|cite]])
- Altman says large enterprises now ask for a consistent package: an agent runtime, a management layer linking data to agents with token-spend oversight, and a workspace for employees. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-31587b1e105588d16720|cite]])
- Altman says ChatGPT is the first really large-scale new consumer product since Facebook, and that OpenAI has done better than he expected against Google, though he calls Google still underrated. ([[2026-04-28-Interview-Altman-Garman-Bedrock-Managed-Agents#^clm-304f2183b2c60e2fb611|cite]])
