# Antithesis

Software testing platform providing deterministic simulations for enterprise systems.

## Facts by source

### 2026-10-15 [[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator|Why AI-Written Software Needs a Flight Simulator]]

- Replit uses deterministic simulation software as a flight simulator to repeatedly test AI-written applications against network disasters and cyberattacks. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-fcd47102d2f46d5b1635|cite]])
- Using generative AI models to evaluate code generates false alarms because probabilistic models behave inconsistently across repeated runs. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-0e340c1a7ba8872cc7a7|cite]])
- Antithesis CEO Will Wilson argues that while AI made code generation simpler, verifying that software works correctly did not get easier. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-7e1edacebccdf6c899e9|cite]])
- Antithesis counts Replit, Palantir, and Datadog among corporate customers using its deterministic software testing platform. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-84237916b93225bc24d7|cite]])
- Antithesis generated more incremental revenue in the August 2026 quarter than across all five preceding quarters combined. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-6b039775513f09a1b323|cite]])
- Antithesis raised $105 million in Series A funding led by quantitative trading firm Jane Street at a $525 million valuation in late 2025. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-47ec6ace804ed39508da|cite]])
- Prediction: Antithesis CEO Will Wilson anticipates that Anthropic and Cursor will eventually release proprietary deterministic testing simulators. ([[2026-10-15-Why-AI-Written-Software-Needs-a-Flight-Simulator#^clm-f283cd3326b244dda08d|cite]])
