# Upwind Security

Israeli cloud cybersecurity startup that monitors cloud workloads and AI agents.

## Facts by source

### 2026-10-22 [[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind|Datadog Offered $4 Billion to Buy Cloud Security Startup ‘Upwind’]]

- Datadog made an offer to acquire Israeli cloud cybersecurity startup Upwind Security for nearly $4 billion. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-e1ab51e3f047ce7a442a|cite]])
- Datadog previously attempted to acquire Upwind Security for roughly $1 billion in 2025 before talks ended. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-957f79973baf2d1c97e0|cite]])
- Upwind Security is finalizing a $300 million funding round at a private valuation of roughly $3.8 billion, fielding multiple takeover bids without accepting an offer. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-5e09a93c2de42cea4c91|cite]])
- Upwind Security develops cybersecurity software to monitor cloud workloads and AI agents, automatically detecting and responding to breaches. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-78c436ec3ecd02b62b6c|cite]])
- Enterprise customers using Upwind Security software include streaming provider Roku and Brazilian digital bank Nubank. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-042a974ec9f24466f506|cite]])
- Upwind Security's annual recurring revenue crossed $50 million, up from about $20 million in ARR at the end of 2025. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-4365a610f6158247fee9|cite]])
- Datadog's nearly $4 billion buyout offer valued Upwind Security at approximately 80 times annual recurring revenue. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-28fe08f7213055faa5c1|cite]])
- Upwind Security was founded in 2022 by Chief Executive Amiram Shachar and raised a $250 million round in January 2026 at a $1.5 billion valuation. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-cd9a447371b9e31cfe38|cite]])
- The proliferation of AI agents independently accessing corporate databases and cloud applications has driven rapid demand for runtime agent monitoring tools. ([[2026-10-22-Datadog-Offered-4-Billion-to-Buy-Cloud-Security-Startup-Upwind#^clm-d983eb078bb48f097f3f|cite]])
