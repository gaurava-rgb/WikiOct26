# Three LLM Inflection Points

Thompson's timeline of AI shifts. One: ChatGPT (November 2022), answers straight from the model. Two: reasoning models, OpenAI o1 (September 2024), where the model thinks before answering and uses many more tokens. Three: working agents, Opus 4.5 (late 2025), where agents call reasoning models many times and one person can run many agents. Each step multiplies demand for compute.

### 2026-03-16 [[2026-03-16-Agents-Over-Bubbles|Agents Over Bubbles]]

- The first LLM inflection point was the ChatGPT launch in November 2022. ([[2026-03-16-Agents-Over-Bubbles#^clm-35028dda6e2470f2ce0a|cite]])
- The second LLM inflection point was OpenAI's o1 reasoning model in September 2024, which reasons over its answer before delivering it. ([[2026-03-16-Agents-Over-Bubbles#^clm-eb57b4a9f0a67c0dde88|cite]])
- Anthropic released Opus 4.5 on November 24, 2025, and by December Claude Code with Opus 4.5 could do things never possible before. ([[2026-03-16-Agents-Over-Bubbles#^clm-3fcad85d76a9aa335faf|cite]])
- Each paradigm raised compute needs: chatbots were cheap at inference, reasoning multiplied tokens per answer, and agents call reasoning models many times and also need CPUs for tools. ([[2026-03-16-Agents-Over-Bubbles#^clm-f44be75ec4759b4c3e16|cite]])
