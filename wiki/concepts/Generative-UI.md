# Generative UI (On-Demand Interfaces)

Software screens that an AI builds on request for one person and one task, instead of a fixed app built once for everyone. The interface can be thrown away and made again whenever it is needed. Thompson sees it as the path from today's apps to AI that shows you just the choices you need at the moment.
