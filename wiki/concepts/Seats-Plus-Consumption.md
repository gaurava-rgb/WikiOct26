# Seats Plus Consumption (Per-User Plus Usage Pricing)

**In one sentence:** Customers pay a fixed fee per person (a seat) plus a metered fee for how much AI agent work they use, which Nadella says business-app customers are shifting to. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings|Microsoft and Apple Earnings]])

## Why it matters
Thompson argues agents are an existential problem for Microsoft 365, because it charges per seat while agents do more than one person's work and cut how many seats customers need. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings|Microsoft and Apple Earnings]]) Nadella predicted every per-user Microsoft business will become a per user and usage business. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings|Microsoft and Apple Earnings]]) Buyers do not always follow: at one consultancy, about half of 400-plus Workday customers signed usage-based AI deals, but only 10% to 20% actively use Workday AI. ([[2026-10-06-Why-the-SaaSpocalypse-Isnt-Over-For-Workday|Workday]])

## Worked example: Microsoft Copilot, 2026
Microsoft Copilot costs $30 per user per month, plus new usage charges for features like Copilot Cowork. ([[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI|Software Discounts]]) In early October 2026 Microsoft launched a revamped Copilot app whose agent parts cost extra based on usage. ([[2026-10-12-How-Microsofts-New-Office-Chief-Fixed-Copilot-and-Won-Over-Nadella|Microsoft's Copilot Fix]]) The meter can sting. One global manufacturer faced roughly $150,000 a month more for GitHub Copilot under usage pricing, so it got a grace period and is weighing Claude Code and Cursor. ([[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI|Software Discounts]])
