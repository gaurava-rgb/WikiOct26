# Seats Plus Consumption (Per-User Plus Usage Pricing)

Microsoft's 2026 description of how its software will be sold once AI agents do work. Customers still pay a fixed license per person (a seat), but they also pay a metered fee for how much agent work they use, like a cloud bill. The shift answers a threat: if agents replace workers, a pure per-seat business shrinks, so the vendor must earn money from usage instead.

## Evidence by source

### 2026-05-06 [[2026-05-06-Microsoft-Earnings-Apple-Earnings|Microsoft Earnings, Apple Earnings]]

- Thompson argues agents are an existential problem for Microsoft 365 because it charges per seat, while agents do more than one person, use far more compute, and reduce how many seats customers need. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings#^clm-f91667c7635b2438944f|cite]])
- Nadella said business-app customers are shifting from the traditional seat model to seats plus consumption. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings#^clm-56b52f0a3a29c37b8688|cite]])
- Amy Hood said Microsoft 365 bookings will look different over time: still a per-seat license, but also a usage meter like Azure that may bill outside bookings. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings#^clm-fcde8e41c45165d096ca|cite]])
- Prediction: Nadella said every per-user Microsoft business, across productivity, coding, and security, will become a per user and usage business, and that this is already happening at scale in coding. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings#^clm-81157905ef0f6b19b5c2|cite]])
- Thompson argues the shift is also an internal lift: Microsoft must change its sales motion and figure out how to pay its salespeople and partners to sell usage instead of seat coverage. ([[2026-05-06-Microsoft-Earnings-Apple-Earnings#^clm-2c695fed38d5201dd132|cite]])

### 2026-09-22 [[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI|Software Firms Discount AI to Keep Customers From Anthropic, OpenAI]]

- Many software vendors are moving from per-seat pricing to usage-based pricing, which can push costs up and has customers grumbling. ([[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI#^clm-4f508c15aab090869bcb|cite]])
- A global manufacturer got at least a month's grace period to keep paying per seat for GitHub Copilot after Microsoft moved to usage pricing, which would add roughly $150,000 a month to its bill; it is weighing a move to Claude Code and SpaceX's Cursor. ([[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI#^clm-09c61850c2ceb6538f46|cite]])
- Microsoft Copilot costs $30 per user per month, plus new usage charges for features like Copilot Cowork. ([[2026-09-22-Software-Firms-Discount-AI-to-Keep-Customers-From-Anthropic-OpenAI#^clm-b259f70dd4c1a77acbcd|cite]])
